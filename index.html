LLM Agent · Dialogue Data Quality

Dialogue Quality Agent: 语义连贯性检测 · 局部改写 · 可复现评测

在数据生产阶段，我负责可控多轮对话生成引擎的架构设计与主要实现， 根据条件组合和模块路径生成合成训练数据，解决人工编写难以覆盖复杂场景组合的问题。

在数据清洗与增强阶段，我负责流水线的重构与主要实现。当时的目标是解决合成数据 过于规整、缺乏真实电话对话特征的问题，补充结巴、重复以及口音导致的转写差异等变化， 提升训练数据的多样性，为模型训练提供更接近真实场景的样本。

我在前两个项目中发现，规则流程能够处理结构和实体问题，却难以覆盖模块切换处的 答非所问与衔接生硬；全量调用 LLM 改写又会增加成本，并引入内容保真风险。 因此，我独立设计并实现对话质量 Agent，设计目标是先检测需要处理的轮次， 再对问题局部进行受约束的改写，并保留原文回退路径。同时，我为 Agent 建立 对照评测与成本记录，用于比较不同策略的检测效果和调用开销。 当前已完成检测与回退，局部改写仍在完善。

可控生成

人工写对话覆盖不了条件组合。用概率矩阵、条件解析和施压策略生成可控样本。

清洗与增强

生成的数据仍有轮次错乱、分布不均、缺噪声。用可插拔流水线做结构治理和鲁棒性增强。

Agent 质量闭环

规则能管实体，管不了跨轮语义。用受约束的工具循环检测、处置，并证明它没有改坏数据。
